# Skill: Mapeamento de Ferramentas & Ecossistema de Execução (Foco em Dados)

## Objetivo
Direcionar automaticamente qualquer melhoria, alteração de código ou estratégia comercial para a ferramenta de prototipagem/design mais eficiente antes de alterar a aplicação em produção.

## Matriz de Seleção de Ferramentas por Tarefa

1. **Stitch**
   - **Uso:** Pipelines de dados, automação de webhooks (Stripe/Supabase), conexões de APIs e integração de fluxos do banco com CRMs externos.

2. **Pomelli**
   - **Uso:** Guia de marca (branding), paletas de cores, identidade visual, anúncios para o plano PRO (R$ 39,90) e padrões estéticos para sites de clientes (R$ 297 a R$ 997).

3. **Google Opal**
   - **Uso:** Prototipagem de prompts, testes de cadeias de IA para o Agente Hermes e criação de "lead magnets" (ferramentas gratuitas para atração de leads).

4. **Google Mixboard**
   - **Uso:** Moodboards visuais, artes conceituais para redes sociais e montagem de propostas de "antes e depois" para prospecção ativa via WhatsApp.

5. **Hermes / Termux (Foco em Dados Core)**
   - **Uso:** Código final em Next.js/Tailwind, testes de build, versionamento Git e deploy direto em produção na Vercel (`foco-em-dados2`).

## Diretriz de Comportamento do Agente
Sempre que o usuário sugerir uma nova funcionalidade, ajuste visual ou estratégia de vendas, verifique primeiro esta matriz e recomende qual ferramenta utilizar na fase de rascunho/validação antes de modificar os arquivos da pasta `src/`.
